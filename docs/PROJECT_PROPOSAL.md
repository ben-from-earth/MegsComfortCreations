# Capstone Project Proposal

## Problem Statement / Overview

For my capstone project, I intend to make a website for one of my connections, who runs a small business on Etsy. Over the past few years, I've noticed several tasks that this person performs manually that could be automated to significantly boost their productivity and increase the number of orders they can complete, especially during the busy holiday season. To support the business, I plan to develop a dedicated website that not only showcases the shops products, but also includes a custom-built tool to assist with backend tasks, like collecting book cover images from Google searches or OpenLibrary, saving book data to a database, and converting the collected images and data into a format that the shop can easily use for orders. This tool will be accessible only to the shop owner via a secure login system.

## Proposal and Stack Focus

This capstone project will be a website created with the MERN stack, and will equally incorporate front-end and back-end development. It will utilize:

1. A database to store and organize user profiles (for newsletter sign-ups, coupon codes, etc.) and tool data (book, movie, video game and album covers).
2. A user-friendly interface to help refine my front-end skills while offering a smooth experience for customers and the shop runner.

## Goals

This project will serve two purposes:

1. Primarily, to showcase my skills as a web developer, and by demonstrating my development in each area of the full-stack. A fully fleshed out web-app like this can be an asset in my portfolio as a way to showcase my capacity to both manage and execute a project for a client.
2. By automating repetitive tasks for the show owner and creating a user-friendly experience for the customer, I can directly provide business growth by decreasing product assembly time, as well as give the shop a way to start growing a user base.

## Target User

The target user for this site will be anyone interested in books or reading. The shop will provide an outlet to purchase trinkets and aids for readers as well as (possibly in the future) a way to track your books, recieve newsletters from the shop owner, etc.
